Community Health Equity Platform

A healthcare analytics platform designed to identify high-risk communities, analyze chronic disease burden, and highlight opportunities to improve health equity.

Key Features

  • Community risk scoring
  • Diabetes rate analysis
  • Clinic and pharmacy resource mapping
  • Trend and correlation analysis
  • Interactive dashboards

Technology Stack

  • Python
  • Pandas
  • SQL
  • Matplotlib
  • Tableau
  • Power BI

Project Goal

Use data-driven insights to help healthcare organizations and public health leaders allocate resources more effectively and improve outcomes in underserved communities.
