# Community Health Equity Platform

A full-stack healthcare analytics platform designed to identify high-risk communities, analyze chronic disease burden, and highlight healthcare resource gaps.

## Project Objective

This platform demonstrates how healthcare organizations and public health leaders can use data to improve health outcomes and allocate resources more effectively.

## Key Features

- Community-level risk analysis
- Diabetes rate trend tracking
- Correlation analysis
- PostgreSQL database integration
- Express API endpoints
- React frontend prototype

## Architecture

Raw Data → Python/Pandas → PostgreSQL → Express API → React Frontend

## API Endpoints

- `/` — API status
- `/communities` — Community health metrics

## Example Metrics

- Community name
- Diabetes rate
- Clinic count
- Risk level

## Business Value

This platform can support:
- Population health analytics
- Health equity initiatives
- Community needs assessments
- Resource allocation decisions
